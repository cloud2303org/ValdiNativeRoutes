# ValdiNativeRoutes v0.1.0

首个版本化的源码模板。下载 `ValdiNativeRoutes-v0.1.0.zip` 或 `.tar.gz`，
解压后修改根目录 `package.json` 的应用名称、Android applicationId、
iOS Bundle ID 和图标，即可安装依赖并开始开发。

```sh
pnpm install --frozen-lockfile
pnpm android
# macOS + Xcode:
pnpm ios
```

## 包含内容

- Android / iOS 原生路由宿主、Valdi TSX 页面与模块脚手架。
- Node / Rolldown 编译、Kotlin / Objective-C / Swift / C++ 绑定生成。
- 固定的 Valdi fork commit 与 Hermes 编译器版本。
- 双端启动屏、同源 PNG 图标与原生 / JS 共享主题。
- ClientSQL SQLite 执行层、Drizzle schema 与 SQL 迁移。
- `app_pages` OTA：手动绑定 App 版本、签名、全量回退、
  Hermes base 编译、HDiff 拆分恢复与默认 ZSTD。
- 固定版本 HDiff 桌面工具自动准备、缓存与 CI 接入。

## 下载包

- `.zip` / `.tar.gz`：同一个提交的完整源码模板。
- `TEMPLATE_RELEASE.json`：模板版本、源码提交、Valdi fork 与工具链版本。
- `SHA256SUMS`：上述下载文件的校验和。

这是源码模板，仍需要 Node 24、pnpm、对应平台的原生开发工具链；
Android 需要 JDK 17 / Android SDK / Bazel，iOS 需要 macOS / Xcode / XcodeGen。
依赖、框架源码和原生产物由正常安装 / prebuild 流程准备。
此版本不附带可直接安装的 APK / IPA 或免编译的运行时 SDK。

新应用如需 OTA，应在第一次原生构建前运行
`node scripts/ota.mjs keygen`，生成自己独立的签名密钥。
私钥不在发布包中；默认 OTA 地址为空。

模板版本 `0.1.0`、原生 App 版本和 OTA `bundleVersion` 各自独立。
后续持续升级建议使用保留 Git 历史的 tag clone；源码 ZIP 本身没有 Git 历史。

详细说明见源码中的 `docs/template-releases.md`。
