# ValdiNativeRoutes v0.1.4

本版同步 Valdi 官方上游，更新 Node 日志转换器，并修复 Web 类型检查、
SnapDrawing 测试资源定位和回调归因测试入口。
Valdi fork 固定为 `70fa9c63a04fbbaa2ddafb53400c0eea6fd5ca27`，
对应官方上游基线 `aed1249d5614cd9afb2c8d43d8177794e28789f0`。

## 框架与编译管线

- 合入上一官方基线 `b527b091` 之后的 32 个提交，包括视图池分批释放、
  Android 圆角重置动画安全转换、Swift 代理缓存加锁、双向文本排版、
  模块 / source map 加载和调试输入错误修复。
- 保留 Hermes `260318099.0.4`、原生 Promise 所有权与销毁保护、
  内部字节码检查、默认 Native Web、OTA 资源 URL 钩子、
  Node 编译后端和 Windows 工具链修改。
- Node 日志转换器跟随上游，通过 `ValdiRuntimeProvider.getValdiRuntime()`
  动态读取日志开关，覆盖运行时后续安装、替换、移除及开关变化。
  ModuleLoader 引导日志保持独立，避免 require 安装前形成加载循环。
- 跟随上游分离测试依赖，将 PropertyList 测试移入 `test/`；
  扩充真实上游 Jasmine 测试入口。
- 修正 Web Unicode 私有 helper 的返回类型推断，兼容 TypeScript 5.9；
  公共接口和发射的 JavaScript 保持不变。
- SnapDrawing 测试通过 Bazel runfiles 与仓库映射查找资源；
  聚焦回调归因测试改用真实 Node 模块归档，并修复重复初始化时的重复注册。
- iOS 构建阶段声明生成的原生模块归档为输出文件。

## 验证

本次上游同步和修复已记录以下本地结果，详细日志索引见
`docs/upstream-20261113-validation.md` 和 `docs/upstream-20261113-fixes.md`：

- 完整根测试通过：508 个 Node 测试、172 个嵌套上游 Jasmine 用例、
  50 项 Unicode 检查、TypeScript 检查和 10 组绑定 golden。

  每轮分别通过 307、12、2 项。
  SnapDrawing 保留 1 项原有禁用测试；回调归因的 QuickJS / JSCore

  Android 三种 ABI、iOS 真机 arm64 和模拟器 arm64 / x86_64 切片构建通过。

- 两套 workspace 的源码 / registry pin 一致；
  vendored 源码规范化既有导入适配后无差异。

以上原生结果来自本地编译和主机测试。本版未重新安装或操作设备，
没有设备 UI / E2E、签名 Release 安装包或性能测量结论。

## 下载与升级

发行包为 `ValdiNativeRoutes-v0.1.4.zip` / `.tar.gz` 源码模板，
并附带 `TEMPLATE_RELEASE.json` 和 `SHA256SUMS`。
依赖缓存、OTA 私钥、APK / IPA 和预编译 runtime 不包含在源码包中。

本版更新框架源码和模块管线。升级时应重新导出所需平台的 runtime，
再构建原生 App，不能仅通过业务 OTA 应用：

```sh
pnpm install --frozen-lockfile
scripts/export-android.sh debug
pnpm build:android
# macOS + Xcode：
scripts/export-ios.sh debug
pnpm build:ios
```

模板版本、原生 App 版本和 OTA `bundleVersion` 继续独立管理。
完整使用与升级说明见 `docs/template-releases.md`。
