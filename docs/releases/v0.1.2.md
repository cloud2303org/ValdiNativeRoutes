# ValdiNativeRoutes v0.1.2

本版整理模板的默认启动、通用路由和本地化能力，并更新 Android 页面承载与主题适配。
保留 `app_pages` 及功能示例，应用可以按自己的业务替换页面。

## 默认启动与路由

- 启动直接进入首页 Tab，移除演示登录页、认证服务、会话 store 和登录退出用例。
  应用自己的认证与持久化策略仍由业务实现。
- 通用的 `createRouter` / `Router` 移至 `app_foundation`，业务模块负责绑定自己的路由表。
  更新页面、宿主生成绑定、文档和从 Home 进入的 E2E 路径。
- Android 调整 Tab 选择、目标页准备和内容容器的所有权，补充选择状态的回归测试。

## 本地化

- Node 构建、编辑器配置和开发监听支持官方 Inline localization：
  模块通过 `strings/strings-*.json` 声明文案，自动生成类型化的 `Strings` 访问器。
- Debug / Release 模块归档携带翻译 JSON，Bazel / Gradle 声明相应构建输入。
  开发时监听文案新增、修改和删除，并沿用官方模块热重载流程刷新依赖页面。
- 首页提供 English、简体中文和跟随系统选项，使用现有 Zustand 状态通知页面刷新。
  其余示例页面没有进行全量翻译；选择不跨启动持久化。

## 原生与构建

- 调整 Android 底部 Tab 样式，以及原生选择页、扫码和 WebView 的主题适配。
- 增加 `cppSourceRoots`，将 `app_pages` 的模块 C++ 生成入口限定为实际实现使用的声明，
  移除不再需要的 `app_foundation` C++ 生成绑定与链接依赖。
  Kotlin / Objective-C 和通用 C++ 生成仍处理各自需要的完整声明。
- 保持现有 Valdi fork 固定提交；默认 runtime 不包含 `valdi_rxjs`。

## 验证

- 两端 Debug runtime 重新导出通过；检查 Android AAR、iOS 设备和模拟器两个 slice，
  均不包含 RxJS 模块资源，必需框架模块仍保留。
- 完整 `pnpm test` 通过：515 项测试，无失败或跳过，绑定 golden 对比通过。
- Android Debug APK 和 iOS Simulator Debug App 构建通过；两个宿主产物也不包含 RxJS 资源。
- Android JVM 单元测试重新执行：159 项通过，11 项因缺少专用 JNI recorder 或 OTA split
  fixtures 跳过，无失败；新增的 7 项 Tab 选择状态测试全部通过。
- 源码发行打包测试通过；只读源码审查未发现具体的 P1/P2 发布阻塞问题。

本轮没有重新安装 App 或执行设备 UI / E2E 回归，也没有验证签名 Release 安装包。
历史设备用例记录不作为本次重新执行的 UI 验收结果。

## 下载与升级

发行包为 `ValdiNativeRoutes-v0.1.2.zip` / `.tar.gz` 源码模板，
并附带 `TEMPLATE_RELEASE.json` 和 `SHA256SUMS`。
依赖缓存、OTA 私钥、APK / IPA 和预编译 runtime 不包含在源码包中。

本版包含宿主源码、生成绑定和 runtime C++ 链接范围变化，升级时重新导出
所需平台的 runtime，再构建原生 App，不能仅通过业务 OTA 应用：

```sh
pnpm install --frozen-lockfile
scripts/export-android.sh debug
pnpm build:android
# macOS + Xcode：
scripts/export-ios.sh debug
pnpm build:ios
```

模板版本、原生 App 版本和 OTA `bundleVersion` 继续独立管理。
完整使用与升级说明见 `docs/template-releases.md`；
本地化格式和行为边界见 `docs/localization.md`。
