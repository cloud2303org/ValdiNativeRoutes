# ValdiNativeRoutes v0.1.3

本版统一 TypeScript 5.9.3，整理类型检查与 Rolldown 管线，并移除模板中的
ClientSQL / Drizzle 集成。Valdi fork 固定提交保持不变。

## TypeScript 与生成输入

- 应用和构建工具统一使用 TypeScript 5.9.3，移除独立的
  `typescript-node` 检查器别名。
- 编辑器、命令行和构建共用模块配置、绝对路径别名与运行时源码范围；
  Node 工具及测试使用独立工程，不再混入运行时工程。
- 所有可达源码和声明参与检查，包括兄弟模块和 npm 声明；
  不通过 `skipLibCheck` 或诊断归属过滤隐藏错误。
- 源码按 Valdi 的 CommonJS 配置检查，实际打包文件另外检查 ESNext 输出要求；
  不支持的 `import = require` / `export =` 写法在输出前报错。
  runtime bootstrap 保留直接 CommonJS 输出。
- 编辑器准备同时生成 Strings 和资源类型；生成 API 使用
  `app_pages/src/Strings`、`app_pages/res` 等规范模块路径。
  物理路径和 `module-build/modules` 符号链接路径都保留检查覆盖。
- Node 测试工程跟随实际选中的 Valdi 源码，支持 `--valdi`、
  `VALDI_SOURCE_ROOT` 和现有 Bazel 源码目录。

## Rolldown 与数据库清理

- 删除旧 `--compare` 路径、`codegen/compare.ts` 和废弃的
  `module-bindings.ts` 入口；原生绑定 golden 和仍在使用的编译入口保留。
- 应用、独立模块和 runtime 构建共用归档哈希实现；
  dev 连接共用经过测试的 `DevPacketReader`。
- 移除 ClientSQL / Drizzle 的应用代码、原生链接选择、Bazel patch、
  schema、迁移、依赖和数据库命令。
  表单直接返回提交结果，不再写入示例数据库；不提供替代 SQL 引擎。

## 二进制数据与性能边界

- 蓝牙和 NFC 的 TypeScript 修复仅完善 buffer 泛型契约。
  完整 buffer 继续复用原生存储，子视图保留精确范围处理，
  发送入口原有的数据快照与后续直接转发语义保持不变。
- 以升级前源码和 TypeScript 5.3.3 重放实际 Valdi 转换器，
  对比升级后的 5 个相关文件，JavaScript 输出完全相同；
  101 个原生绑定文件也完全相同。
- 增加共享底层存储输入、原生回复和记录字段的 buffer 身份、
  子视图范围与不重复复制的回归覆盖。
  本版没有为满足类型检查增加运行时复制、检查或包装。

## 验证

- 完整 `pnpm test` 通过：483 项测试，无失败或跳过；绑定 golden 通过。
- `pnpm typecheck` 通过：15 个运行时模块和 3 个 Node 工程。
- `pnpm build` 通过，包含独立模块的 Node / Bazel 编译与全部模块归档。
- 15 个模块分别从物理路径和符号链接路径检查，共 30 次检查，零诊断。
- 两个子项目的冻结锁文件安装通过；保留依赖版本及 Valdi patch 哈希未改变。
- 独立源码审查未发现本次整理与升级引入的具体 P1/P2 问题。

本轮最终验证覆盖源码、模块管线和生成绑定；没有重新导出原生 runtime、
构建 APK / IPA、运行设备 UI / E2E 或进行硬件性能测速。
源码发布不代表这些平台运行验证已经完成。

## 下载与升级

发行包为 `ValdiNativeRoutes-v0.1.3.zip` / `.tar.gz` 源码模板，
并附带 `TEMPLATE_RELEASE.json` 和 `SHA256SUMS`。
依赖缓存、OTA 私钥、APK / IPA 和预编译 runtime 不包含在源码包中。

本版移除了 ClientSQL 原生链接及相关 patch。已有 AAR / XCFramework
可能仍包含旧模块，升级时应重新导出所需平台的 runtime，再构建原生 App；
不能只替换业务 OTA 包：

```sh
pnpm install --frozen-lockfile
scripts/export-android.sh debug
pnpm build:android
# macOS + Xcode：
scripts/export-ios.sh debug
pnpm build:ios
```

模板版本、原生 App 版本和 OTA `bundleVersion` 继续独立管理。
完整使用与升级说明见 `docs/template-releases.md`。
