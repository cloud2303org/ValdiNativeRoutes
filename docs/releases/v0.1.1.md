# ValdiNativeRoutes v0.1.1

本次更新让页面自行绘制背景，移除路由宿主统一底色，并包含自 v0.1.0
以来的 Native Web、原生模块组织和构建流程更新。

## 页面与路由

- Android 页面和 tab 内容容器不再绘制统一的主题底色，正常窗口取消背景
  drawable；Valdi 页面和原生页面分别控制自己的背景。
- iOS 根容器和页面承载容器改为透明，移除固定浅色背景。
- Android 系统启动页保留明暗背景资源，关闭系统 Force Dark，由应用控制配色。
- Android 默认底部 tab 内容高度从 56dp 调整为 48dp，保留系统安全边距。

## 框架与原生模块

- 标准 runtime 集成 Native Web；应用入口安装 Fetch、streams、WebSocket
  等全局 Web API，业务页面无需重复安装。
- 同步 Valdi fork，并更新 Bazel 管理的 Rust 1.99.1 工具链。
- 整理原生模块实现和依赖声明，加入静态 Vision 集成，并更新构建与升级文档。

## 验证

- `pnpm test` 通过：484 项测试，无失败或跳过，绑定 golden 检查通过。
- Android Debug 和 iOS Simulator Debug 构建通过。
- Android 测试环境完成 Valdi 详情页、原生 Compose 选择页及返回操作检查。
- Meizu 20 覆盖安装后完成用户实机验收，确认本次背景显示问题已解决。
- iOS 本次完成构建验证，未进行模拟器或实机 UI 验收。

页面检查不代表所有转场逐帧验证；本次未添加固定延时或等待内容就绪的路由逻辑。

## 下载与升级

发行包为 `ValdiNativeRoutes-v0.1.1.zip` / `.tar.gz` 源码模板，
并附带 `TEMPLATE_RELEASE.json` 和 `SHA256SUMS`。
依赖缓存、OTA 私钥、APK / IPA 和预编译 runtime 不包含在源码包中。

从旧版升级时，需要重新导出所需平台的 runtime，再构建原生 App：

```sh
pnpm install --frozen-lockfile
scripts/export-android.sh debug
pnpm build:android
# macOS + Xcode：
scripts/export-ios.sh debug
pnpm build:ios
```

本次修改包含 Kotlin、Swift 和 Android 窗口主题，需要更新原生安装包，
不能仅通过业务 OTA 应用。模板版本、原生 App 版本和 OTA `bundleVersion`
继续独立管理。完整使用与升级说明见 `docs/template-releases.md`。
